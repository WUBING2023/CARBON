# Data and checkpoint availability

The repository includes the small AARS HDF5/checkpoint demonstration plus selected author-generated frozen arrays, result tables, scripts and run metadata. It includes the published small source workbooks and measured-score records needed by the paper, with original provenance. It excludes raw sequencing, reference genomes, complete model weights, large database distributions, dependency source archives, private reference code and personal screenshots.

research/catalog/EXTERNAL_ASSETS.csv records archive-relative locations, sizes and original SHA256 for omitted experiment assets. A local-only source-location index accompanies the review work directory and is deliberately outside this repository. The manifest is an index, not a download service or proof that an unbundled file is accessible offline.

research/catalog/BENCHMARK_WEIGHT_AVAILABILITY.csv covers the current canonical 222-task cohort: CARBON 221, iDeepB 219, RBPNet 222. CARBON lacks SERBP1_K562_ENCSR121GQH. iDeepB lacks AKAP1_HepG2_ENCSR356ZMO, BUD13_HepG2_ENCSR830BSQ and SERBP1_K562_ENCSR121GQH. The ablation baseline checkpoint for SERBP1 exists but is not established as the same historical benchmark checkpoint and must not substitute silently.

The older local Zenodo reconstruction contains 222 weights but includes TROVE2_HepG2_ENCSR993FMY and lacks current SERBP1_K562_ENCSR121GQH. The 221 overlapping SHA identities agree. Its count alone does not establish current-cohort coverage. No fresh public Zenodo download, public DOI route or full Code Ocean reproduction has been verified for this candidate.

Upstream data and full weights require a separate authorized archive with exact version, task list, hashes and access instructions. No fictional public link is supplied. The original measured RNAcompete tar.gz is a single explicit soft-limit exception: 51,769,595 bytes, SHA256 bf65e4bdd12fb1f8fd5db585e5165db24cc1dba6a1b2708f2cc0e12255a676bd, included under paper/source_data/S23_external_order_preferences/original/sources/. GitHub large-file warning behavior has not been tested. The 115,308,739-byte uncompressed matrix is not placed in Git; scripts/extract_rnacompete_source.py verifies it by streaming or extracts it outside the repository. Other candidates above 50,000,000 bytes, including the full ClinVar VCF, remain external and are explicitly indexed.
