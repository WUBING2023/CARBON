# Provenance and path transformations

The real base is the 71-file GitHub main snapshot at 40ca6bfe3b7d601a08aa7aa68abcebd5773f5317. The research sources come from the checked 2026-10-17 archive; the manuscript copy comes from revision_v33/manuscript. No original source directory is modified.

SOURCE_MANIFEST.csv identifies every physical candidate file, its current SHA256, original source label/relative path, original SHA256 and transformation. ASSET_ALIASES.csv lists byte-identical duplicates held as one canonical copy; ALIAS_PROVENANCE.csv preserves their original source identities. MANUSCRIPT_BINDING.json separately binds the manuscript source and figure/input artifacts. Dataset and figure bindings list actual paths, not planned uploads. SUPPLEMENT_DATA_BINDINGS.csv explicitly connects every S1–S27 dataset to its real research/experiments/E## guide and current source-data files.

Private account prefixes are replaced only in candidate text copies: user project directories under /home are mapped to /data/CARBON_PROJECT; other personal home paths become /data/USER_HOME. These generic anchors are not available input directories. Replace them in a new scratch run. Original and transformed hashes are separate. Scientific tables/arrays are not numerically altered by redaction. The local-only LOCAL_SOURCE_LOCATIONS.csv remains outside Git and resolves original machine paths.

Copied historical reports and original experiment documentation describe their original run packets. Their availability statements and relative paths are historical records; current inclusion is determined by SOURCE_MANIFEST.csv, each INCLUDED_FILES.csv and the external/alias catalogs. The top-level README and docs describe the current candidate. Small published measurement workbooks and original score metadata are included with their original source terms; unrelated private reference archives and personal screenshots are excluded.

Current checks establish file identity, saved-result arithmetic and one real CPU demonstration. They do not establish exact original source snapshots for every early run, a clean dependency installation, all historical renderer replay, fresh full-study training, fair comparator rescoring or independent biological validation.

EQUIVALENT_SOURCE_CONTENT.csv points omitted historical source paths to identical original content included elsewhere. This is a byte identity lookup, not evidence that two experiment runs, tasks or biological observations are equivalent.

The repository .gitattributes disables text newline conversion so frozen CSV/JSON/source hashes remain byte-identical across Windows and Linux Git checkouts. This is separate from checksum verification of the actual Git payload.
