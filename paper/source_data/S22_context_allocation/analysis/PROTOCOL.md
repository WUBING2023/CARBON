# Context expansion: prospective rules on excluded chromosome 1

Frozen at 2026-10-04 10:58 UTC, before reading chromosome-1 eCLIP outcomes or running its predictions in this campaign. This is a rule-frozen new-range confirmation, not a newly generated independent study. Existing raw chr1 data may have been examined by other past project analyses; an exposure audit is required. The matched protocol excluded chr1 from all its training, validation and previous test inference.

Question: when the same short canonical motif occurs twice in one native RNA window, does the authentic conservation-assisted model more accurately allocate measured local crosslink support than the sequence and necessary trained conservation controls? This is a contextual recognition-rule question, not a bound/unbound classification or physical contact probability.

Fixed tasks: PTBP1, HNRNPK and RBFOX2 in K562 and HepG2, all six existing matched tasks, seeds 11/23/47 and separately trained aligned/sequence_only/mean/permuted. No new training, head choice or task/seed exclusion. Strict matched checkpoint state loading. All three seeds and their native-profile average ensemble will be exported. A seed is not a biological replicate.

Input eligibility is the same as the previous same-window protocol, now applied to chr1: PTBP1 word CTCT; HNRNPK CCCC; RBFOX2 TGCATG in ACGT encoding. Sites are enumerated left-to-right, centers floor(start+(length-1)/2), restricted to 5..95. Retain the first two non-overlapping sites at least 12 nt apart. Both supports are the inclusive 11 nt neighborhood c−5:c+6. Fixed representative is minimum SHA256(task|chromosome|source_row) in each connected overlapping-window component on the same strand; no model outcome enters eligibility. No per-task cap unless more than 10,000 representatives, in which case first 10,000 hashes. Whole windows are native 101 nt, not artificially relocated sequence constructions.

Three input-defined, nested scenes only; all must be reported:

1. All eligible identical canonical short-word pairs (main scene).
2. The two sites also have identical centered 7-mer sequence (c−3:c+4), refining rather than claiming full PWM-equivalent binding strength.
3. The same 7-mer scene additionally has |mean native PhyloP in site support 1 − site support 2| ≥ 0.5. This tests a preregistered contrasting-context hypothesis; the cutoff is fixed, not selected from chr1 model wins. PhyloP units and sign are retained.

The main cohort within each scene uses input-adjusted measurable signal: y_i=sum(eCLIP support i), b_i=sum(input support i), total Y/B over the entire 101 nt, r_i=y_i−(Y/B)b_i. Require Y>0, B>0, both r_i≥0, and r_1+r_2>0. Do not clip negative residuals. q=r_1/(r_1+r_2). This is a conditional residual-signal share, not a calibrated binding probability. Qualification is based on measurable targets identically for every model; it is not an aligned-model-win filter. Export disqualifications and raw signals for all sequence-qualified pairs.

Primary endpoint is squared paired-share error (p−q)^2, p=m_1/(m_1+m_2) from the native probability-profile neighborhood masses. The ensemble averages the three native profile vectors before local shares. Primary contrasts Full−Sequence, Full−Mean, Full−Permuted, each equally weighted by gene within task and tasks macro-averaged; pooled pair weighting is separate and not a fallback primary. Freeze a fixed p=.5 share baseline. Ranking correctness at non-tied q is secondary; ties remain in continuous endpoint and never count as wins. Simple PhyloP direction, centered distance, GC and within-support input direction are secondary ranking rules, not label-fitted share predictions.

Gene annotation uses available GENCODE v29 coordinates if verified. Ambiguous overlapping genes or unmapped cases are explicitly recorded. Independent uncertainty units are gene per task; gene-equal summaries include one representative loss per gene, computed as the mean over its locus representatives. Across-task same genes are clustered by genomic gene ID in macro bootstrap if shared. If reliable gene mapping cannot be achieved, use connected genomic loci with a clear narrower independence claim; never call overlapping windows independent RNA samples. Retain per-task/per-gene/per-locus counts and all seed effects.

Raw eCLIP q=y_1/(y_1+y_2), nonzero sum with ties, is a prespecified sensitivity. Same ranking and squared-share definitions. Do not switch the main residual endpoint to raw because it wins. Main macro three-contrast family uses Bonferroni 95% intervals (quantiles .05/(2*3),1−.05/(2*3)). Three scenes create nine primary hypothesis contrasts; also provide simultaneous Bonferroni9 bounds. Per-task effects, seed effects, and pooled analyses are exploratory supporting analyses, fully exported; no positive isolated case is treated as a general conservation advantage.
