## Supplementary Methods S1.19: reference audit and revised figure display

### Reference provenance and the Figure 3b display rule

The source-aware audit uses the human CISBP-RNA Build 2.00 `RBP_Information_all_motifs.txt` metadata and the corresponding PWM files. The retained local acquisition record dates this database download to 27 March 2026; the Build 2.00 designation and source definitions were checked against the [official homepage](https://cisbp-rna.ccbr.utoronto.ca/), [bulk-download page](https://cisbp-rna.ccbr.utoronto.ca/bulk.php) and [help page](https://cisbp-rna.ccbr.utoronto.ca/help.html) on 12 October 2026. It joins each of the 193 S6 comparisons on exact `cisbp_RBP_Name = RBP_Name` and `Target_ID = Motif_ID`, rather than on motif identifier alone. Multiple database records for the same pair are retained in the accompanying metadata table. The audit records `RBP_Status`, `Motif_Type`, source identifier, source type, source author/year and PMID. A D label alone is insufficient to define experimental support: JPLE motifs are classified as inferred even when `RBP_Status` is D. Direct experimental eligibility requires a D record and a measured motif type among RNAcompete, HTR-SELEX, RNA-Bind-n-Seq or SEQRS. D motifs compiled through RBPDB are retained as a separate database-compiled class; I records are classified as homology-inferred unless their motif type is JPLE.

The 193 comparisons comprise 126 direct experimental, 54 JPLE-inferred, 11 database-compiled and two homology-inferred comparisons. At the original q < 0.05 threshold, these classes contribute 45, 25, two and zero passing comparisons, respectively. No p, E or q values were recalculated after the cognate join or source restriction. Consequently, these are classifications of the original search results and do not define a new experimentally restricted Tomtom testing family. The 121 comparisons failing q < 0.05 remain in the table.

Figure 3b displays QKI, PUM2, HNRNPA1, HNRNPL, RBFOX2 and U2AF2 in that fixed order. These named display examples link different sequence preferences to the atlas and the retained PUM2/HNRNPA1 sensitivity illustrations; they are not a random sample or an estimate of the recovery rate. For each RBP, positive pattern 0 comparisons with direct experimental eligibility are sorted by task identifier and then reference identifier, and the first row is displayed. Neither p/q values nor model performance enter this ordering. This rule selects QKI HepG2/M00068_2.00, PUM2 K562/M00558_2.00, HNRNPA1 HepG2/M00044_2.00, HNRNPL HepG2/M00049_2.00, RBFOX2 HepG2/M00413_2.00 and U2AF2 HepG2/M00099_2.00. The last selection of reference ID can therefore retain a non-significant reference despite other available significant references for the same protein; RBFOX2 provides such an example.

Logos are generated from the exact exported query PPM and the matched reference PWM, with information content in bits against a uniform A/C/G/U background. The retained Tomtom optimal offset and orientation determine the common alignment coordinates; reverse-complement orientation is applied when recorded. For the main-panel display only, the common span is centered on the aligned reference and has length max(9, reference length + 2) nucleotides. Both logos use the same horizontal nucleotide spacing and vertical information-content scale. Full matrices, offsets, orientations, overlap lengths, p/q values and the display bounds are retained in Data S24 and the figure source package. Cropping is a display operation and does not redefine the motif comparison.
