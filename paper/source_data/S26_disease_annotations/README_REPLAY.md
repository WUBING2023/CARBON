# Data S26: disease annotation joins

Run `python replay_disease.py` from this directory to reproduce the eight-variant/thirteen-event join from saved exact official annotation tables and existing prediction/source rows. Run `python render_disease_supplement.py` for the native S27 atlas (NumPy/Matplotlib required). No models are retrained or queried.

The complete 191 MiB dated ClinVar snapshot remains in the private research work directory; its official URL/digests and retained source rows are here. This offline replay does not repeat the full database search or establish that missing records are biologically absent. Direct current ESummary and GDC aggregate replies are archived. No controlled patient data, browser credentials, copyrighted reference figures or model training inputs are included.

ASB labels and predictions were previously exposed. Clinical/tumor annotation is not an independent RBP binding endpoint. Aggregate VCV disease lists are not per-condition causality assertions; all thirteen cases and errors are retained.
