# 保守性分数实验与主图（Figure 6）完全说明

本文档整合 **`保守性分数实验/`** 的方案与全量结果，以及 **`图/figure6/`** 主图的数据来源与制图逻辑，供 Methods/Results 统一引用。叙述顺序为：保守性（PhyloP）与真实结合信号的共定位 → 保守性通道相对消融模型的性能增益是否集中于高保守区域。

**Figure 6 四面板与正文结构对应（无 A/B/C/D 角标，仅逻辑对应）：**

| 面板 | 图中标题（英文） | 主要依托实验 | 回答的问题（一句话） |
|:----:|------------------|--------------|----------------------|
| **A** | Peak-centered conservation | **实验一** + test 集 h5 抽样聚合 | 以峰段中心对齐后，observed peak 上平均 PhyloP 是否高于 matched non-peak 的聚合曲线？ |
| **B** | Cross-task enrichment | **实验一** `task_summary` / `cross_task_summary` | 每个 task 的峰−对照 PhyloP 差（Δ）在 222 个 task 上是否整体为正、跨 task 检验是否显著？ |
| **C** | Representative loci | **实验四** 选 task + **同一** h5 窗口 + 消融权重 | 在叙事选定的两个 101 bp 例上，PhyloP、eCLIP 观测与 CARBON / No-cons 预测是否呈现「高保守处更贴近观测」的直观对比？ |
| **D** | Gain by conservation bin | **实验四** `bin_summary`（`peak_core_phyloP`） | 按 peak-core 保守性分箱后，ΔPCC 是否随 bin 升高；bin3−bin0 跨 task 配对是否显著？ |

## 一、研究背景与总体目标

RNA 结合蛋白（RBP）结合位点的进化保守性常被用作功能约束的间接指标。本仓库在 MARCP 框架下使用 **5 通道输入**：碱基 one-hot 占前 4 维，第 5 维为 **位点级保守性分数（PhyloP，与 `in_channels=5` 一致）**。由此自然产生两类可检验问题：

1. **生物学合理性（相关性）**：在控制序列与信号强度等混杂因素后，**真实 eCLIP 峰区**是否比对照区域表现出更高的 PhyloP？
2. **模型方法学价值（更接近干预对比）**：**含保守性通道的完整模型（文中主图展示名 CARBON / baseline）**相对 **去掉保守性通道的消融模型（no_conservative）**，预测性能的提升是否**随局部保守性升高而增大**？

实验一、二、四分别从峰级、motif 级、分层消融作答；**Figure 6** 只呈现与主叙事最强对齐的统计与图型，弱证据不放在视觉中心。

**阅读关系。** `保守性分数实验/` 侧重**可检验假设、统计口径与表格字段**；`图/figure6/` 侧重**把已定稿的数值与曲线变成版式固定的主图**。二者共用同一套 h5、同一套 `find_peaks` 与同一批全量运行输出；正文若写「如图所示」，应以图中角标/图注与 `outputs` 中 JSON、CSV **交叉核对**。

## 二、数据约定与共同设定

**数据。** Test 染色体 **chr1/8/15**，`数据/h5data/<task_id>/_5ch/*_5ch.h5`；`X (N,101,5)` 中 **`X[...,4]`=PhyloP**，`Y`/`Y_ctl` 为 observed/control；元数据 `df` 与 `_5ch` 逐行对齐（`chromStart`、`chromEnd`、`strand` 等）。

**峰。** 窗内 `find_peaks(Y)`，默认 **max≥2 或 sum≥4**；summit=`argmax(Y)`。此为**窗内 peak**，与 whole-batch flatten 后 `find_peaks` **不等价**，论文须写清。

**规模。** 全量约 **222 task**；主结论依赖**跨 task 分布与合并检验**。

## 三、实验一：峰级保守性富集（Peak-level）

**主图对应：Panel A（峰中心聚合曲线）与 Panel B（跨 task Δ 分布）。**

**目的。** 在**同一 101 bp 窗内**，比较 **observed peak 区域**与 **matched non-peak 对照**的平均 PhyloP；对照在设计上匹配 GC、`Y` 总量与 `Y_ctl` 总量等，以降低非生物学混杂。实现上，对每个峰段在窗内抽取与峰段等长、落在非峰掩码上的背景区间（并满足采样与匹配约束），再比较两侧 PhyloP 摘要量；跨窗汇总时在 task 内先聚合、再跨 task 做合并检验，避免把「窗」与「task」两层单位混写。

**输出。** `实验一/outputs/full_run/`：`task_summary.csv`、`cross_task_summary.json`、`qc_per_task.csv`、`peak_table.csv`（字段见实验一方案 §13）。

**结果（强）。** 跨 task：`median_delta_across_tasks≈0.0516`，正效应占比 `≈0.941`，Wilcoxon **p~10^-34**。即匹配对照下峰区 **系统性更保守**；此仅为**富集/相关性**，「模型是否用到保守性」见实验四。

- 上述 **跨 task 数字**即 **Panel B** 图内统计条/检验应对齐的 `cross_task_summary.json`；**Panel A** 为同一套峰定义与 PhyloP 通道下的**空间聚合可视化**（脚本中可对峰数抽样以稳定曲线，全局推断仍以 JSON 为准）。

## 四、实验二：Motif / seqlet 中心分析（补充层级）

**主图对应：无（Figure 6 不含 Panel 对应实验二）。**

**目的。** 将保守性从窗口级推进到 **TF-MoDISco 给出的 motif instance**：比较 **motif core 与 flank** 的 PhyloP，并做 position-wise 的 CWM/IC 与 PhyloP 的相关及置换检验。

**主要文件。** `实验二/outputs/full_run/` 下含 `motif_instance_table.csv`、`motif_position_table.csv`、`motif_level_CI_summary.csv`、`cross_task_summary.json` 等。

**结果（补充）。** Core vs flank 整体 **p≈0.98（不显著）**；位置层面 CWM/IC 与 PhyloP 仍有相关（见 `实验过程和基本结果.md`）。**不宜**作「motif core 必更保守」的主结论；主文仍以实验一、四为主。

## 五、实验四：保守性分层下的消融收益（方法学主证据）

**主图对应：Panel C（代表性基因座轨道）与 Panel D（按 `peak_core_phyloP` 分箱的 ΔPCC 趋势）。**  
其中 **Panel C** 用实验四的 `bin_summary` **挑选 task**（如 bin3 与 bin0 的 Δ 差异较大的 task），再在 h5 中抽窗并加载 **baseline / no_conservative** 权重做前向预测；**Panel D** 直接汇总 **实验四** 的分层 ΔPCC。

**目的。** 对同一批 test 窗口，比较 **baseline（5 通道，含 PhyloP）**与 **no_conservative（4 通道）** 的预测指标；在每个 task 内按保守性摘要变量分位数分为 **4 个 bin**，计算  
**Δmetric = metric_baseline − metric_no_conservative**，并检验 Δ 是否随 bin 索引单调上升。同一窗口上两模型输入除第 5 通道外一致，故 Δ 可归因于「是否注入 PhyloP」这一干预；分层则在「高/低保守语境」下比较该归因效应的大小，而非重新估计相关性。

**分层变量（重要）。** 常用两类：  
- `window_phyloP`：窗口平均 PhyloP；  
- `peak_core_phyloP`：**仅在含峰窗口上**定义的 peak core 平均 PhyloP（无峰窗记 NaN，不参与该分层）。  

输出：`实验四/outputs/full_multi/`，核心为 **`bin_summary.csv`**，辅以 `task_level_scores.csv`、`cross_task_correlation.json` 等。

**要点。** `peak_core_phyloP` 分层下，多数 task 的 **median ΔPCC 随 bin 上升**（正趋势比例约 **92%**，详载 `实验过程和基本结果.md`）。Task 级 Spearman（富保守 vs 总体 Δ）**弱、 p≈0.08**，仅作补充。**主证据**为每 task **bin3−bin0** 的 median ΔPCC 再在 222 task 上 **Wilcoxon**（`peak_core_phyloP` 分层极显著）。主文以 **PCC/Spearman** 为主；flattened AP 在低样本 bin 可能不稳。

## 六、主图 Figure 6（`图/figure6`）的设计、数据与出图

**叙事句（与 `画图方案.md` 一致）。**  
*Conservation scores are biologically enriched at true binding peaks and preferentially improve model performance in highly conserved regions.*

**脚本与导出。** `图/figure6/make_figure6.py`。默认输出 **`panels/panel_A`–`panel_D` 的 PDF/PNG**（独立子图；画布比 **A 9:7、B 23:21、C 27:29、D 23:29**，便于拼 1:1 大正方形）。`--write-composite` 可选整张图。配色见 **`图/画图总方案`**（NPG），白底。

以下按 **Panel A → D** 与上文实验章节一一对应。

### Panel A（对应第三节「实验一」+ h5）

- **内容：** test 染色体上抽样含峰窗口，以 **峰段几何中心** 为 0 对齐，聚合 **observed peak** 与 **matched non-peak** 的 mean PhyloP 曲线，半透明 **bootstrap** 置信带；竖虚线标峰心。  
- **数据：** 与 **实验一** 同一 `find_peaks` 与 PhyloP 定义；直接读 `数据/h5data/.../_5ch/`。角标 **n≈… peaks** 为脚本抽样量。  
- **与 Panel B 分工：** A 给**空间形状**（峰邻域是否隆起），B 给**跨 task 效应量分布**。

### Panel B（对应第三节「实验一」汇总表）

- **内容：** 每个 task 一个 **Δ mean PhyloP（peak − matched bg）**；**violin + box + 抖动点**；图内上方统计条为 **n tasks、median Δ、Wilcoxon P**（来自 `cross_task_summary.json`）。  
- **数据：** `实验一/outputs/full_run/task_summary.csv` 中 **`delta_median`** 等；检验与 **第三节** 全量结论一致。  
- **与 Panel A 分工：** 同一生物学结论的 **1D 汇总**（222 点）与 **2D 聚合曲线**互补。

### Panel C（对应第五节「实验四」选 task + 同一窗口上的预测展示）

- **内容：** 上下两个 **101 bp** 例：**高保守、高增益** / **较低保守、较弱增益**；每例含轨道 **PhyloP（浅填）**、**Observed**、**CARBON（五通道 baseline）**、**No-cons（四通道消融）**，峰区浅阴影。坐标行为 **`{task_id} chr:start:end:strand`**。  
- **数据：** Task 由 **`实验四/outputs/full_multi/bin_summary.csv`** 按「bin3−bin0 median ΔPCC」等规则选取；窗口自 **h5** 与元数据对齐；预测来自 **`消融实验/.../MARCP/<task>/baseline|no_conservative/model_params.pth`**。  
- **与 Panel D 分工：** C 是 **个案机制展示**，D 是 **全队列分箱统计**；二者同属实验四叙事，但 **C 不重复画 bin 曲线**。

### Panel D（对应第五节「实验四」`bin_summary`）

- **内容：** 分层变量 **`peak_core_phyloP`**，横轴 **bin0–bin3**；每个 task 一条 **浅透明折线**（四 bin 的 median ΔPCC），叠加跨 task **median 粗线 + IQR 带**；**y=0** 虚线；角标 **bin3−bin0 median** 与 **P**。  
- **数据：** `实验四/outputs/full_multi/bin_summary.csv`（`stratification == peak_core_phyloP`）；与 **第五节**「bin3−bin0 Wilcoxon」一致。  
- **与 Panel B 分工：** B 答「峰是否更保守」，D 答「保守性通道带来的 **预测增益** 是否在高保守 peak core 更大」。

**元数据：** `panels/panels_export.meta.json`。

**与实验的一致性核对（建议投稿前自检）。** **Panel A/B** 与 `实验一/outputs/full_run/cross_task_summary.json`；**Panel D** 与实验四 `peak_core_phyloP` 分层及 bin3−bin0 检验；**Panel C** 的 task 与坐标在 `bin_summary` 与 h5 **可追溯**。
