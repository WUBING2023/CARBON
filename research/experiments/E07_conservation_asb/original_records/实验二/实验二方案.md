实验方案 2
方案名称

Motif-centered conservation analysis around TF-MoDISco seqlets

1. 核心科学问题

模型识别出的 motif/seqlet 核心位置，是否比 motif flank 或伪 motif 实例更保守？

2. 要验证的具体假设

高保守性不是均匀分布在 binding window 中，而是更集中在 motif core / high-contribution motif positions 上。

3. 所需输入数据
TF-MoDISco seqlets 或 motif instances
CWM / PPM
若已有：Tomtom significant motif matches
observed eCLIP peak 信息
PhyloP per-base scores
可选：known motif PWM/FIMO scan results
4. 具体分析设计

主设计

从 TF-MoDISco motif clusters 中选：
全部 high-confidence clusters，或
更保守的写法：仅选 Tomtom q < 0.05 的 motifs
收集每个 motif instance / seqlet 的 aligned coordinates。
对每个 instance 计算：
motif core mean PhyloP
motif flanks（例如左右各 5–10 nt）mean PhyloP
peak-overlapping vs non-peak-overlapping instances
再做 position-wise alignment：
按 motif center 对齐
画 relative position 的平均 PhyloP metaprofile

更强版本

用 motif position importance 定义 core：
CWM absolute contribution 高的位置
PPM / IC 高的位置
检验 “高 IC / 高 CWM 的 motif positions 是否也更保守”

对照

同一窗口中的 motif flanks
shuffled motif instances（保持 nucleotide composition）
motif scan 命中但不落在 peak 中的实例
5. 实现流程图式步骤
读取 TF-MoDISco seqlet BED / HDF5 / motif instance 表。
统一 orientation，对齐到 motif center。
用 pyBigWig 抽 motif core 与 flank 的 PhyloP。
输出 instance-level 表和 motif-level 汇总表。
画 motif-centered metaplot、core-vs-flank violin、motif heatmap。
可进一步做 position_importance ↔ phyloP 的 position-wise correlation。
6. 统计检验与量化指标
instance-level paired Wilcoxon：core vs flank
motif-level conservation index：
CI = mean_phyloP(core) - mean_phyloP(flank)
对每个 motif 或 task 统计 CI，再跨 task 汇总
position-wise Spearman correlation：
abs(CWM) or IC vs mean_phyloP(position)
permutation test：随机打乱 motif position labels
7. 预期可能出现的结果模式

支持时

motif center 附近出现明显 conservation peak
core > flank
在 Tomtom-supported motifs 中更明显
高 IC / 高 CWM 位置也往往更高 conservation

不支持时

conservation 只在 broader peak region 富集，不集中于 motif core
不同 motif 差异很大
只有少数 canonical RBP motif 有该模式
8. 可解释性与论文价值

这是最直接的 motif-level association 证据。它能把 conservation 从“窗口级额外特征”提升到“与模型恢复的 binding grammar 对齐”的层面，非常适合接入你已有的 TF-MoDISco 结果。

9. 风险与局限
motif discovery 本身带有模型偏好
unmatched motifs 里有技术偏倚，尤其 U-rich 伪模式
若 motif instance 数不足，task-level 统计不稳
对非序列特异性较强的 RBP 可能信号较弱

缓解方式

主分析仅纳入 high-confidence / Tomtom-supported motifs
supplementary 再展示 unmatched motifs 的 exploratory pattern
每个 motif 至少要求最小 instance 数
