
## 实验目标

本系列“保守性分数实验”用于回答两类问题：

- **生物学合理性（相关性）**：真实 eCLIP binding 峰/模型识别出的 motif 核心位置是否更保守（PhyloP 更高）？
- **模型方法学价值（更接近因果）**：将保守性（PhyloP）作为输入通道后，模型相对“去掉保守性通道”的消融模型是否获得性能增益？且增益是否集中发生在高保守区域？

本实验默认使用与 MARCP 数据管线一致的 **5 通道输入**：`X[...,0:4]` 为 one-hot（A/C/G/U），`X[...,4]` 为 **保守性分数 PhyloP**；`Y` 为 observed eCLIP profile，`Y_ctl` 为 control profile。分析窗口为 test 染色体 **chr1/chr8/chr15** 的 101bp 窗，默认使用与 Figure4 一致的 test BED 子集过滤。

---

## 实验设计与流程概览

### 实验一：峰级保守性富集（Peak-level，Tier A）

- **核心做法**
  - 在每个 101bp 窗内，对 observed 信号 `Y` 用与 MARCP 一致的 `find_peaks` 定义 **peak 掩码**（默认阈值：`max>=2` 或 `sum>=4`）。
  - 对每个峰段（连续 peak 区间）提取 `X[...,4]` 上的保守性统计量（如峰段均值、summit±k）。
  - 在同一窗口内抽取 **等长 non-peak 区间**作为对照，并匹配 **GC + `Y` 总量 + `Y_ctl` 总量**（减少 GC、信号强度等混杂）。
- **统计汇总**
  - task 内：peak vs matched non-peak 的配对差值（效应量）与 Wilcoxon。
  - 跨 task：对每个 task 的差值分布做合并检验，并统计正效应占比。

### 实验二：Motif/seqlet-centered 保守性（TF-MoDISco 结果对齐）

- **核心做法**
  - 读取 TF-MoDISco 的 seqlet/motif instance 坐标，将每个实例对齐到 motif center。
  - 比较 **motif core vs flank** 的 PhyloP（来自 `X[...,4]`，与实验一一致）。
  - 额外做 position-wise 分析：例如 motif position 的 **CWM/IC** 与 position 平均 PhyloP 的相关（含置换检验）。

### 实验四：保守性分层下的消融收益（最直接的“模型作用”证据）

- **核心做法**
  - 对同一批 test 窗口，比较两模型预测性能：
    - **baseline（5 通道，含保守性）= MARCP**
    - **no_conservative（4 通道，不含保守性）**
  - 对每个窗口计算保守性 summary，并按分位数分层（默认 4 bins）：
    - `window_phyloP`（窗口平均 PhyloP）
    - `peak_core_phyloP`（peak core 平均 PhyloP；无峰窗为 NaN，不参与该分层）
  - 在每个 bin 内计算性能并取差值：\(\Delta metric = metric_{baseline} - metric_{no\_conservative}\)
  - 对每个 task 检验 \(\Delta metric\) 是否随 bin 升高呈上升趋势（Spearman/Kendall）。

---

## 基本结果（本次全量输出）

### 结果 1：峰区域显著更保守（实验一，强证据，生物学合理性成立）

实验一跨 222 个 task 的汇总（`保守性分数实验/实验一/outputs/full_run/cross_task_summary.json`）：

- **跨 task 中位数效应**：`median_delta_across_tasks = 0.0516`
- **正效应 task 占比**：`fraction_delta_gt0 = 0.9414`
- **跨 task 检验**：`wilcoxon_vs0_pvalue = 3.42e-34`

解释：在控制 GC、`Y` 与 `Y_ctl` 等匹配条件下，**observed peak 内的 PhyloP 仍系统性高于 matched non-peak**。这为“保守性通道与真实结合峰一致”提供了很强的生物学一致性证据。

> 注意：这条证据证明的是 **保守性分数与 binding 峰的相关性/富集**，并不等价于“模型一定用到了它”或“引入它一定提升性能”。

### 结果 2：motif core vs flank 的整体差异不显著，但位置层面存在统计相关（实验二，中等/补充证据）

实验二跨 task 汇总（`保守性分数实验/实验二/outputs/full_run/cross_task_summary.json`）：

- **实例级 core vs flank 配对检验**：`p = 0.9756`（`n = 9308`）→ **整体不显著**
- **位置层面相关（全局）**：
  - `rho_cwm = 0.0829`，`p = 3.14e-15`（并有置换检验 `perm_p_cwm ≈ 0.005`）
  - `rho_ic = -0.2906`，`p = 3.89e-175`
- **分 cell line 的 CI（core-flank）**：K562 与 HepG2 方向不完全一致（提示异质性）。

解释：实验二不适合作为“motif core 一定更保守”的主结论；更适合写成“模型识别出的 motif 位置特征与保守性在统计上存在结构性关系，但方向/异质性需要更谨慎解释”。

### 结果 3：保守性越高，保守性通道带来的性能收益越大（实验四，针对“模型作用”的主证据）

实验四（`保守性分数实验/实验四/outputs/full_multi/`）用“消融 + 分层”的方式评估保守性通道价值。关键观察是**趋势方向的普遍一致性**：

- **按 `window_phyloP` 分层**（4 bins）：
  - `median_delta_pcc_vs_bin`：222 个 task 中 **78.4% 为正趋势**
  - `median_delta_spearman_vs_bin`：222 个 task 中 **88.3% 为正趋势**
- **按 `peak_core_phyloP` 分层**（只在有峰窗上分箱）：
  - `median_delta_pcc_vs_bin`：222 个 task 中 **91.9% 为正趋势**
  - `median_delta_spearman_vs_bin`：222 个 task 中 **93.2% 为正趋势**

解释：在绝大多数 task 内，**高保守 bin 中 baseline 相对 no_conservative 的收益更大**，符合“保守性信息在高保守区域更有用”的方法学叙事。

#### 跨 task 的相关性（弱证据/边缘显著）

`cross_task_correlation.json` 给出 task 层面的相关（n=222）：

- `spearman_r = 0.118`
- `spearman_p = 0.0796`

解释：这表示“一个 task 的 conservation 富集程度（落在最高 bin 的窗口占比）”与“该 task 的总体消融收益（mean ΔPCC）”之间的相关 **为正但偏弱**，本次输出中 **未过 0.05**。更适合写为“趋势一致但强度有限”，而不是强结论。

补充说明（这句话的含义）：

- 这里的 `spearman_r ≈ 0.118` 表示 **相关方向为正但效应很小**：在 222 个 task 这一层面上，“更富保守的 task”只表现出**非常弱**的“更吃保守性通道”的倾向。
- `spearman_p ≈ 0.080` 表示：在“真实相关为 0”的原假设下，观测到这么大（或更大）相关的概率约为 **8%**，因此按常用阈值 \(p<0.05\) 不能称为“统计显著相关”，更稳妥写法是 **弱证据/边缘趋势**。

#### 更“硬”的跨 task 总结（bin3 vs bin0 的配对检验）

相比 task 级相关，更直接的跨 task 证据是：对每个 task，取最高保守 bin（bin3）与最低保守 bin（bin0）的 `median_delta_pcc` 之差，再在 222 个 task 上做 one-sample Wilcoxon：

- `window_phyloP` 分层：`median(bin3-bin0) = 0.00449`，正差占比 `0.784`，`p = 1.44e-20`
- `peak_core_phyloP` 分层：`median(bin3-bin0) = 0.01110`，正差占比 `0.919`，`p = 1.29e-32`

解释：跨 task 上，**最高保守分层的消融收益显著大于最低保守分层**；这比“task 级相关”更直接支持“保守性通道的收益在高保守区域更集中”的结论。

## 是否证明了“保守性分数在模型中的作用”？

- **已证明（强）**：保守性分数在真实 binding 峰区域显著富集（实验一，跨 task 极显著），支持其作为输入特征的生物学合理性。
- **较直接地支持（中-强）**：通过 baseline vs no_conservative 消融，并在 task 内按保守性分层观察到绝大多数 task 的 \(\Delta\) 性能随保守性升高而增大（实验四），说明保守性通道带来的收益**不是均匀的**，更集中在高保守区域。
- **尚不足以强力支持（弱/需补强）**：跨 task 层面“富保守 task 更依赖保守性通道”的相关目前较弱（\(r\approx 0.118, p\approx 0.080\)），适合作为补充趋势而非主结论。

---

## 局限性与注意事项（写法建议）

- **相关性 vs 因果性**：实验一证明的是峰更保守（相关性）；实验四才是消融对照（更接近因果）。
- **分层统计的离散性**：4 个 bin 下 Spearman/Kendall 的取值会较离散（大量出现 \(r=\pm1\)），因此更建议报告“正趋势比例 + 关键 bin 的效应量差异”。
- **AP 指标口径**：实验四的 flattened AP 与 `train_ops.calculate_batch_metrics_whole` 对齐，会把 bin 内窗口拼接成一维，低样本 bin 上可能不稳定；主结果建议以 window-wise PCC/Spearman 为主。
