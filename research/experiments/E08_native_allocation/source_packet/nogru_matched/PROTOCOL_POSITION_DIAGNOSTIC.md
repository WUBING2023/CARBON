# Position-prior diagnostic, registered 2026-10-04 12:39 UTC

This is a post hoc diagnostic prompted by the completed Full-versus-NoGRU result. It does not replace the registered PTBP1 combined chr1/X/Y primary endpoint or its cohort. No conclusions have yet been computed for the following new definitions.

1. Use all 1,851 uniquely gene-mapped, input-adjusted measurable pairs in the registered main cohort. Keep the original 11-position supports, original nonnegative residual eligibility, observed ties, and three training seeds. Never fit a rule to observed shares.
2. For each of two fixed position-only profiles, g(t)=exp[-0.5((t-50)/sigma)^2], sigma=15 or 25 nt, sum g over the original two 11-position supports and form the two-site share. Report both profiles, their gene-equal squared-share error and non-tied ranking. Neither sigma is selected as a new main baseline. This symmetric profile does not exhaust learned absolute-position priors.
3. Define d=abs(abs(c1-50)-abs(c2-50)) from inputs. Report Full-minus-NoGRU error and ranking on the nested d=0, d<=2 and d<=5 subsets. These post hoc strata may be small and cannot become a selected new primary. They control symmetric distance to the window center, not arbitrary 5-prime versus 3-prime position effects.
4. Report the existing Phi, GC, window-center and input-mass ordering rules on this same cohort, plus an input-only pyrimidine rule (C+T proportion within each 11-position support). Rules with tied scores receive half credit. Observed equal-share pairs are excluded only from ranking, retained for error.
5. Mean locus losses within each true GENCODE gene and task, then weight genes equally within each cell and the two cells equally. Joint gene-ID cluster resampling across both cells uses NumPy PCG64 seed 20261007 and 10,000 replicates. Save exact bootstrap means and RNG state per subset. Report ordinary 95% intervals plus Bonferroni 3 intervals for the three Full-NoGRU position strata, and Bonferroni 2 intervals for Full versus the two Gaussian profiles. Neither adjusted family changes the original primary analysis.
6. Preserve raw per-pair shares, distances, error, rankings and cohort identity. Model seeds are training replicates, not independent RNAs. A persistent advantage after these diagnostics supports a path-associated advantage beyond simple symmetric center preference; it alone does not prove sequence-context causality, because the capacity difference and more flexible position priors remain.
