# Phase 2 — sequence ambiguity and local conservation

Frozen 2026-10-04 11:38 UTC, before inspecting chrX/Y labels or new predictions. This is the second registered hypothesis; the first chr1 hypothesis and all negative controls remain intact.

Question: when a sequence-only model allocates almost equal profile mass to two occurrences of the same short consensus in a native RNA window, does correctly positioned conservation resolve that ambiguity in agreement with eCLIP signal? This is a local conditional allocation question, not binding probability, physical contact, biochemical mechanism or complete-profile fidelity.

Development: chr1 results were inspected and motivate PTBP1 as a local candidate because both cells have favorable Full point estimates. No universally positive Phi effect was found. The new PTBP1 primary is explicitly development-selected, not six proteins with independent confirmation. chrX/Y were excluded from matched training and validation, but broader project history may contain these chromosomes; this is a new frozen rule test, not a completely blind study.

Inputs: all available chrX and chrY native101nt windows for six fixed matched tasks; chrM is not analyzed. PTBP1 CTCT, HNRNPK CCCC, RBFOX2 TGCATG. Select first two left-to-right occurrences with centers5..95 and separation>=12; each support is inclusive c−5..c+5. Input-only minimum SHA256(task|chromosome|original source_row) per connected overlapping, same-strand chromosome component; at most10000 per task/chromosome, never select by labels or Full victories. Strict whole-window same-strand GENCODEv29 containment; exactly one real ENSG geneID for gene-level main endpoint. Ambiguous/unmapped are reported separately, not placeholder genes.

Three scenes: (1) all_core, (2) ambiguous_S where abs(ensemble Sequence share−0.5)<=0.1, (3) ambiguous_S_phi05 adding absolute mean local Phi support difference>=0.5. The engineering share-margin0.1 is fixed from chr1 development (29.16% of eligible PTBP1 strict-adjusted pairs) and will not be changed after new labels. It is not calibrated model uncertainty. No identical7 eligibility shrinkage in main; exact centered7-mer equality remains a descriptive support field. The complement abs(S−0.5)>0.1 is retained as a specificity check rather than silently discarded.

Primary population: PTBP1 both cells, ambiguous_S scene, strict input-adjusted measured shares with native Y total>0, input total>0, r1,r2>=0 and r1+r2>0, where r_i=y_i−Y_total*b_i/B_total. Negative residuals are excluded, never clipped; observed ties retained for continuous MSE. No observed support minimum other than nonzero denominators. Raw shares y1/(y1+y2) including observed ties are a mandatory sensitivity; further thresholds are not tried.

Prediction: probability profile from the already fixed output head, three seed11/23/47 native profiles averaged in float64 before the local support ratio p=p1/(p1+p2). All four matched trained arms Full/aligned, Sequence, Mean, Permuted. Mean uses all101 Phi values; Perm uses original source_row and chromosome X/Y with PCG64 row_key('20260929|task|chromosome|row') and the same permutation across seeds. All seed profiles, native counts, transform hashes and original IDs are saved. The fixed0.5 share is a simple baseline; Phi/GC/window-center/input-mass direction simple rules are not fitted to labels.

Endpoint: gene-level mean squared paired-share error (p−q)^2, then equal mean over represented genes in each cell, then equal mean of both cells. Contrast is Full−control, negative means closer measured local share. Primary family3 controls: Sequence/Mean/Permuted; paired genomic geneID bootstrap10,000 with deterministic PCG64 seed20261005, simultaneous Bonferroni3 intervals [.05/(2*3),1−.05/(2*3)]. Same geneID sampled jointly across cells. Model seeds are not biological replication. If any cell has no represented genes, primary is not estimable; no zero fill or reweighting after outcomes. Individual seeds and pair-pooled means separately reported.

Supporting families: all3 proteins×3 scenes×3 controls, Bonferroni27;6 task contrasts×3scenes×3controls, Bonferroni54. Marginal95%CIs included only as exploratory. Preserve invalid bootstrap count when no task/cell genes represented. Ranking excludes observed q=.5, prediction=.5 scores0.5; ties not victories. Record S-wrong→Full-right and reverse, bothright/bothwrong. Continuous improvement decomposed algebraically as 2*(pFull−pS)*(q−pS)−(pFull−pS)^2; this is a prediction shift analysis, not attributing biological causal positions.

Exposure sensitivity: audit old chrX/Y coordinate tables using actual chromosomes; exclude overlaps and previously exposed gene names jointly, while retaining the main cohort. Absence from this ledger is not proof of global blindness. Native eCLIP and input units are stored profile units, not asserted raw read counts without provenance confirmation.
