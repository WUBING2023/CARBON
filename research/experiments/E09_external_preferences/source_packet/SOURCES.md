# Primary sources and retained provenance

- Original RNAcompete measurements and metadata are from the author-maintained [morrislab/RBPbinding repository](https://github.com/morrislab/RBPbinding), pinned to tree `b67d8fba065b3c010da672a4980c4ed440745710`. The downloaded [original 420-experiment Z-score archive](https://raw.githubusercontent.com/morrislab/RBPbinding/b67d8fba065b3c010da672a4980c4ed440745710/Data/Zscores_420_origrncmpt.tar.gz) was verified against its author Git blob SHA1 `1bf4ebb9103ea17dfe734e00f26f3e6d29a96508`. These are original measured columns, distinct from JPLE predictions in the same repository. Construct, study provenance, hybridization identity and reported split-half correlations are retained in `results/WIDE_EXPERIMENT_METADATA.csv`, with the original S1 metadata table in `sources/`.
- The earlier human protein source is [Ray et al., Nature 2013](https://doi.org/10.1038/nature12311); HNRNPK RNCMPT00026 and PTBP1 RNCMPT00268/RNCMPT00269 have original human-gene identity verified in that metadata. PTBP3 is not used as a substitute for PTBP1. The two PTBP1 columns share the same protein identity and are not counted as two proteins.
- HNRNPK RBNS: [ENCODE ENCSR368NMO](https://www.encodeproject.org/experiments/ENCSR368NMO/), released original five-mer enrichment file ENCFF715DIL, verified MD5 `543b8593092378c5b79a81ec99261898`. Native R scores were obtained from [the public ENCODE object](https://encode-public.s3.amazonaws.com/2015/08/17/62258dcb-87fa-4252-a415-20ab000b2872/ENCFF715DIL.tsv).
- RBFOX2 RBNS: [ENCODE ENCSR441HLP](https://www.encodeproject.org/experiments/ENCSR441HLP/), original five-mer enrichment file ENCFF002DFE, verified MD5 `6f38bb80a1028cf593b0cc6977e3228d`. [Public ENCODE object](https://encode-public.s3.amazonaws.com/2014/06/10/d5eb4c42-c4e5-4d11-9b9e-d6f6ad051ecc/ENCFF002DFE.tsv).
- PTBP1 ENCSR651NGR is revoked and contains no released usable files in the downloaded record; it is not presented as positive RBNS ground truth. Earlier Hugheslab links returned404 and the GEO request did not yield data; failed fetches are retained in `sources/FETCH_ATTEMPTS.json`.
- Figure design exemplar: actual complete local RBPNet Fig.4 at `../..//interpretability_reading_20261004/assets/rbpnet_fig4.png`, with reading notes and original primary paper retained by root. The figure is a design/evidence-chain reference; its data, logos, target/control architecture or conclusions are not transplanted into CARBON.

Original externally measured seven-mer and source files are retained in `sources/`, not downloaded anew at evaluation time. The original assay pool/construct differences are documented without claiming they explain disagreement. Author split A/B correlations are metadata, not an independently repeated raw split analysis by this project. Local native input/checkpoint identities remain private user materials and have not been sent to another external service.


Final text parsing contract: original score-token floats are read with round_trip, equal to Python float(token). All 622,516 selected original measured tokens were independently compared bitwise. Original authors’ scores and source archives are not edited; corrected support tables and pre-correction snapshots are separated. See PARSER_ADDENDUM.md/PARSER_QA.json.
